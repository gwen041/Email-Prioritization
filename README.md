EMAIL PRIORITIZATION WITH DISTILBERT



An AI-powered email prioritization system that uses a fine-tuned DistilBERT model to automatically classify and rank emails by urgency and importance.



\## Project Structure



email-prioritization-distilbert/

* backend/        # Express.js, TypeScript, API
* frontend/       # Next.js, Tailwind CSS user interface
* models/         # DistilBERT model weights (not tracked by git)
* data/           # Enron email dataset samples
* tests/          # Unit and integration tests
* docs/           # Documentation and architecture notes



\## Tech Stack

\- Model: DistilBERT (via HuggingFace Transformers)

\- Backend: Express.js, TypeScript

\- Frontend: Next.js, Tailwind CSS

\- Dataset: Enron Email Dataset
